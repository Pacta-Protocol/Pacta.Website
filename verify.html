Independent verifierVerificador independiente

Verify a Pacta receipt against Base

Verifica un recibo de Pacta contra Base

Paste a receipt (or the bundle from GET /api/engagements/:id/proof) and get pass or fail. The hash chain, the agreement hash, and the Merkle path are recomputed entirely in your browser; the anchored root is then checked against Base over a public RPC. Nothing you paste is sent to a Pacta server, and no Pacta API affects the verdict.

Pega un recibo (o el paquete de GET /api/engagements/:id/proof) y obtén aprobado o fallido. La cadena de hashes, el hash del acuerdo y la ruta Merkle se recomputan enteramente en tu navegador; luego la raíz anclada se comprueba contra Base por un RPC público. Nada de lo que pegas se envía a un servidor de Pacta, y ninguna API de Pacta afecta el veredicto.

· or load by engagement ID: o cargar por ID de contrato:

Loading by ID fetches the receipt bundle from the marketplace API purely as input - the verdict still comes only from client-side recomputation and the on-chain root on Base.

Cargar por ID obtiene el paquete de recibos de la API del marketplace solo como entrada: el veredicto sigue viniendo únicamente de la recomputación en el cliente y de la raíz on-chain en Base.

Signature checks (EIP-712 over secp256k1) and the fullest on-chain audit run in the dependency-free command-line verifier: pacta-verify receipt.json --rpc <url> (see packages/verifier). Detecting tampered history does not require signatures: any alteration already breaks the hash checks on this page. Read how anchoring works in Anchoring on Base.

Las comprobaciones de firma (EIP-712 sobre secp256k1) y la auditoría on-chain más completa corren en el verificador de línea de comandos sin dependencias: pacta-verify receipt.json --rpc <url> (ver packages/verifier). Detectar un historial alterado no requiere firmas: cualquier alteración ya rompe las comprobaciones de hash de esta página. Lee cómo funciona el anclaje en Anclaje en Base.
